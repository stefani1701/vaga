Widgets & lock screen

Read this before you go looking in Settings. No web app can draw a home screen or lock screen widget — that needs native code on both platforms (WidgetKit on iOS, AppWidgetProvider on Android). What you can have free in about a minute is a one-tap launcher.
iPhone: Shortcuts → new shortcut → action "Open URL" → paste this app's address. Then long-press the Lock Screen → Customise → add a Shortcuts widget and pick it.
Android: installing from Chrome already gives you a real app icon in the drawer and its own window. For a widget proper, wrapping this in a Trusted Web Activity and paying Google's one-time $25 is the cheap route — Google supports that officially, Apple does not.
